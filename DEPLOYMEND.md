# Deployment

For more info, see the [frontend's deployment documentation](https://github.com/satisfactorymodding/smr-frontend/blob/staging/DEPLOYMENT.md).

## Staging

The `staging` branch automatically deploys to ficsit.dev via fluxcdbot on Vilsol's internal `ficsit-app` private repository.
It can take upwards of 20 minutes to deploy once something is merged.

## Production

The production smr-api is hosted on Vilsol and Night's server stack.
Deployments are manual.

To find out what version is currently live, ask Vilsol to check it.
